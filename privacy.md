# プライバシーポリシー

最終更新日: 2026-10-26

本ポリシーは、YouTube チャンネル『史料で解く日本史』（@shiryo-nihonshi、以下「本チャンネル」）の運営者が、本チャンネルの制作・投稿・分析のために使う社内ツール「shiryo-nihonshi autopilot」（以下「本ツール」）での情報の扱いを定めるものです。

## 1. YouTube API サービスの利用

本ツールは YouTube API サービス（YouTube Data API v3・YouTube Analytics API・YouTube Reporting API）を利用しています。本ツールを利用することで、利用者は [YouTube 利用規約](https://www.youtube.com/t/terms) に同意したものとみなされます。Google による情報の扱いは [Google プライバシーポリシー](https://policies.google.com/privacy) をご覧ください。

## 2. 利用者

本ツールは本チャンネルの運営者 1 名が、自分の管理するチャンネルにだけ使います。第三者の Google アカウントやチャンネルへのアクセスは求めず、一般には提供していません。

## 3. 取得する情報

運営者が OAuth で許可した範囲で、次の情報を取得します。

- 本チャンネルの動画・再生リストのメタデータ（タイトル、説明、公開設定、公開予定日時、サムネイル）
- 本チャンネルの集計された分析データ（視聴回数、総再生時間、視聴者維持率、インプレッション数とクリック率など）

視聴者個人を特定できる情報（コメント投稿者、登録者の一覧、個々の視聴者の行動など）は取得しません。

## 4. 利用目的

- 本チャンネルへの動画・サムネイルのアップロード、公開予定の設定、再生リストの整理
- 動画のタイトル・サムネイルの改善と、次に作る題材の判断のための分析

上記以外の目的（広告配信、データの販売、他サービスとの照合など）には使いません。

## 5. 保存

- OAuth の認可情報（更新トークン）は運営者の端末内にだけ保存し、外部に送信しません。
- YouTube Analytics API・YouTube Reporting API から取得した分析データは、集計値として運営者の端末と、運営者だけがアクセスできる非公開のリポジトリに保存し、傾向の比較のために 30 日を超えて保持することがあります。その場合も、30 日ごとに認可が有効であることを確かめます。
- それ以外に YouTube Data API から取得した情報（動画のメタデータなど）は、取得から 30 日以内に更新または削除します。
- 運営者が認可を取り消した場合、または本ツールの利用をやめた場合は、保存した認可情報と分析データを削除します。

## 6. 第三者への提供

取得した情報を第三者に販売・提供することはありません。ただし、分析と制作の補助のために、集計された分析データを AI サービス（Anthropic の Claude）の処理に渡すことがあります。この処理は運営者のアカウントで行い、本ポリシーの目的の範囲に限ります。

## 7. Cookie 等

本ツールはウェブサイトではなく、運営者の端末で動くプログラムです。利用者の端末に Cookie 等を保存したり、端末の情報を収集したりしません。

## 8. 認可の取り消し

本ツールに与えたアクセス権は、いつでも [Google アカウントのセキュリティ設定（サードパーティのアクセス）](https://myaccount.google.com/connections) から取り消せます。

## 9. お問い合わせ

本ポリシーに関するお問い合わせは次の連絡先までお願いします。

- 連絡先: jc.kamijoe@gmail.com

## 10. 改定

本ポリシーを改定する場合は、このページで最終更新日とともに告知します。

# Privacy Policy (English)

Last updated: 2026-10-26

This policy describes how the operator of the YouTube channel "史料で解く日本史" (@shiryo-nihonshi, the "Channel") handles information in "shiryo-nihonshi autopilot" (the "Tool"), an internal tool used to produce, upload and analyze the Channel's videos.

## 1. Use of YouTube API Services

The Tool uses YouTube API Services (YouTube Data API v3, YouTube Analytics API and YouTube Reporting API). By using the Tool, users agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). See the [Google Privacy Policy](https://policies.google.com/privacy) for how Google handles information.

## 2. Users

The Tool is used by a single person, the Channel operator, and only for the Channel the operator manages. It never requests access to any other Google account or channel and is not offered to the public.

## 3. Information accessed

Within the scopes the operator grants through OAuth, the Tool accesses:

- Metadata of the Channel's own videos and playlists (title, description, privacy status, scheduled publish time, thumbnail)
- Aggregated analytics of the Channel (views, watch time, audience retention, impressions and click-through rate, etc.)

The Tool does not access information that identifies individual viewers (commenters, subscriber lists, individual viewer activity, etc.).

## 4. How information is used

- Uploading videos and thumbnails to the Channel, setting scheduled publish times, and organizing playlists
- Analyzing performance to improve titles and thumbnails and to choose future topics

Information is not used for any other purpose, such as advertising, selling data, or combining it with other services.

## 5. Storage

- OAuth credentials (refresh token) are stored only on the operator's computer and are never transmitted elsewhere.
- Data retrieved through the YouTube Analytics API and YouTube Reporting API is stored as aggregated figures on the operator's computer and in a private repository accessible only to the operator, and may be kept longer than 30 days to compare trends. In that case, the Tool confirms every 30 days that its authorization is still valid.
- Other information retrieved through the YouTube Data API (such as video metadata) is refreshed or deleted within 30 days of retrieval.
- If the operator revokes access or stops using the Tool, stored credentials and analytics data are deleted.

## 6. Sharing

Information is never sold or provided to third parties. Aggregated analytics may be processed by an AI service (Anthropic's Claude) to assist with analysis and production. This processing runs under the operator's own account and is limited to the purposes in this policy.

## 7. Cookies

The Tool is a program running on the operator's computer, not a website. It does not store cookies on, or collect information from, users' devices.

## 8. Revoking access

Access granted to the Tool can be revoked at any time from the [Google Account security settings (third-party access)](https://myaccount.google.com/connections).

## 9. Contact

- Contact: jc.kamijoe@gmail.com

## 10. Changes

Changes to this policy will be announced on this page together with the last-updated date.
