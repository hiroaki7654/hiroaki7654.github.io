# 史料で解く日本史 — shiryo-nihonshi autopilot

This page describes the internal tool used by the operator of the YouTube channel [史料で解く日本史](https://www.youtube.com/@shiryo-nihonshi) to upload and analyze the channel's own videos. The tool uses YouTube API Services. It runs only on the operator's computer, accesses only the operator's own channel, and is not offered to the public.

このページは、YouTube チャンネル『[史料で解く日本史](https://www.youtube.com/@shiryo-nihonshi)』の運営者が、自分のチャンネルの動画の投稿と分析に使う社内ツールの説明です。本ツールは YouTube API サービスを利用しています。運営者の端末でのみ動き、運営者自身のチャンネルにだけアクセスし、一般には提供していません。
